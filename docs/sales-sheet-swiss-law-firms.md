# LexFlow — Sales Sheet for Swiss Law Firms

## One-liner
Modern practice management for Swiss law firms: cases, documents, client portal, messaging, Swiss VAT billing, time tracking, and optional on-premise deployment.

## Why Swiss firms choose LexFlow
- **Swiss-ready billing:** CHF, Swiss VAT rates, Adyen/Stripe payment links  
- **Client portal:** shared documents, case status, outstanding invoices  
- **Security posture:** RBAC, audit logs, SIEM export, encryption controls  
- **Deployment choice:** SaaS multi-tenant **or** on-premise single-tenant with offline license  
- **Data protection pack:** DPA template (FR/DE), TOMs, residency certificate  

## Core modules
| Module | Capability |
|--------|------------|
| Matters | Cases, assignments, timeline |
| Documents | Folders, versions, visibility, AI summary |
| Messaging | Case threads + email notifications |
| Billing | Invoices, payment plans, PDF letterhead |
| Time | Timer, submit workflow, invoice from hours |
| Admin | Firm settings, invites, superadmin (SaaS) |

## Packaging (indicative)
- **Starter** — small teams, core matters + documents  
- **Pro** — billing, time tracking, client portal  
- **Enterprise / On-prem** — single-tenant, offline license, custom residency
