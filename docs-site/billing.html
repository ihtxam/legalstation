Billing & invoices

Time tracking

Track billable time against cases, optionally with the floating timer, then convert entries into invoice lines.

Invoices

  • Create draft invoices, add line items, apply Swiss VAT rates.
  • Generate PDF / Swiss QR-bill when firm banking details are set.
  • Optional installment (payment plan) schedules.

Online payments

Firms can configure Adyen (firm-level merchant keys) and/or Stripe. Checkout priority is Adyen → Stripe → offline / QR.

Client view

Clients see open invoices in the portal and can pay online when a gateway is configured.
