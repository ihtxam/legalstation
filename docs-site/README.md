# Cliavo Help Center (`docs.cliavo.com`)

Static self-support documentation for merchants.

## Publish

1. Point `docs.cliavo.com` at any static host (Nginx, Cloudflare Pages, S3, etc.).
2. Upload the contents of this folder as the site root.
3. Optionally keep serving the same files from the app at `/help` (already wired in the Cliavo server).

## Local preview

Open `index.html` in a browser, or visit `/help` on a running Cliavo instance.
