Sécurité

Les cabinets d'avocats traitent des informations couvertes par le secret professionnel : la sécurité est donc intégrée à chaque couche — authentification forte, isolation stricte des locataires, transport chiffré et opérations de plateforme auditées.

Mots de passe & connexion

  • Les mots de passe sont stockés sous forme de hachages scrypt salés — jamais en clair.
  • Longueur minimale de 8 caractères ; le changement de mot de passe exige le mot de passe actuel.
  • Les comptes provisionnés avec un mot de passe temporaire doivent définir un nouveau mot de passe à la première connexion.
  • Les sessions sont des cookies signés et HTTP-only ; Se déconnecter invalide immédiatement le cookie de session.
  • Les connexions superadmin (plateforme) sont séparées des connexions cabinet — un superadmin ne peut pas accéder à l'interface du cabinet via la connexion normale, et inversement.

Authentification à deux facteurs (2FA)

  • Tout utilisateur peut activer la 2FA TOTP sous Paramètres → Sécurité : scannez le code QR avec Google Authenticator, 1Password ou toute application TOTP, puis confirmez avec un code.
  • Après chaque connexion par mot de passe, un code à 6 chiffres est requis. La 2FA est redemandée à chaque nouvelle connexion — les codes ne sont jamais « mémorisés » d'une connexion à l'autre.
  • La désactivation de la 2FA exige un code actuel valide.

Isolation des locataires

  • Chaque enregistrement (client, dossier, facture, document, message…) est rattaché à votre cabinet. Toutes les requêtes filtrent par appartenance au cabinet — un autre cabinet ne peut ni lire ni écrire vos données.
  • Les clients n'accèdent qu'à leurs propres données via le portail ; les notes internes restent internes.
  • Les vérifications de rôles s'appliquent à chaque opération côté serveur, pas seulement via des boutons masqués dans l'interface.

Chiffrement & infrastructure

  • Tout le trafic est en HTTPS (TLS via Let's Encrypt) ; les requêtes HTTP sont redirigées.
  • Les jetons OAuth des calendriers sont stockés chiffrés au repos.
  • L'hébergement repose sur une infrastructure suisse (résidence des données en CH) avec la base de données sur un réseau privé, inaccessible depuis internet.
  • Les téléchargements de fichiers sont servis via des routes authentifiées avec vérification des chemins.

Audit & opérations de plateforme

  • Les chronologies de dossiers enregistrent chaque action importante par affaire.
  • Les actions administratives au niveau de la plateforme (création de cabinets, changements d'offre, impersonation, annonces) sont consignées dans un journal d'audit superadmin.
  • L'impersonation par le support est explicite, temporaire, auditée et clairement signalée dans l'interface pendant qu'elle est active.

Sauvegardes & disponibilité

  • La base de données de production s'exécute avec des volumes persistants et des exports planifiés ; renseignez-vous auprès du support sur la politique actuelle de sauvegarde et de rétention de votre déploiement.
  • Un déploiement sur site/mono-locataire avec licence hors ligne est disponible pour les cabinets ayant des exigences d'hébergement strictes — contactez Cliavo.

Signaler un problème de sécurité

Vous avez trouvé quelque chose ? Écrivez à support@cliavo.com avec « SECURITY » dans l'objet. Merci de ne pas effectuer de tests sur les données d'autres cabinets.
