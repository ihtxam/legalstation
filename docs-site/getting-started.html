Getting started

Cliavo is a multi-tenant platform for law firms: each merchant (firm) has its own workspace, branding, clients, and billing.

Sign in

  • Firm users sign in with email and password on your firm login URL.
  • If 2FA is enabled, enter the authenticator code after password login.
  • Platform operators use the separate superadmin login.

First firm setup

  • Complete firm profile (name, address, VAT, logo, banking for Swiss QR).
  • Invite lawyers, assistants, and sub-admins from Settings → Team.
  • Adjust role permissions under Settings → Roles if needed.
  • Connect payments (Adyen and/or Stripe) under Settings → Payments.

Languages

The product UI supports English, French, German, Italian, and Arabic. Users can change language in Settings.
