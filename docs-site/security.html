Security & roles

Two-factor authentication (2FA)

Enable TOTP under Settings → Security. After password login, users must enter a code from their authenticator app.

Roles

  • Admin — full firm settings, team, CMS, analytics.
  • Subadmin / Lawyer / Assistant / Client — access controlled by the firm role matrix.

Admins can customize the authorization matrix in Settings → Roles.

Invites

Staff and clients join via secure invite links. Temporary passwords may be emailed when a firm is provisioned.
